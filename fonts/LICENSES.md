# Caption fonts

Static cuts made by `scripts/build-fonts.py` from the variable fonts in
[google/fonts](https://github.com/google/fonts), each renamed to its own family so ffmpeg's
subtitle renderer (libass) picks the right weight. All are under the SIL Open Font License
1.1; the full texts are in `licenses/`.

| Inter-ExtraBoldItalic.ttf, Inter-Black.ttf | Inter ExtraBold Italic, Inter Black | Inter, The Inter Project Authors | licenses/Inter-OFL.txt |
| Montserrat-*.ttf | Montserrat ExtraBold Italic, Montserrat Black Italic, Montserrat ExtraBold | Montserrat, The Montserrat Project Authors | licenses/Montserrat-OFL.txt |

| Anton-Regular.ttf | Anton | Anton, The Anton Project Authors | licenses/Anton-OFL.txt |
